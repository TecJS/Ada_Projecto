# Ada_Projecto
Estas son instruciiones para usar en linux pero no deberia ser muy diferente a windows

primero debemos tener el entorno para trabajar con python

```
python3 -m venv .venv
```

Activamos el entorno

```
source .venv/bin/activate
```

```
pip install numpy
```
```
pip install pandas
```
```
pip install scikit-learn
```

```
pip install matplotlib
```
